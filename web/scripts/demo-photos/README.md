# Real photos for the demo accounts

Drop photos into a folder named after the place and the seeds (`npm run seed`, `npm run seed:jp-hk`, `npm run seed:friends`) use them instead of the generated postcards.
The nightly reset re-uploads them, so they never disappear. Any JPG, PNG or WebP works. If a folder has fewer photos than the place needs, they are reused in order.
The place's location comes from the seed script, not the photo, so photos without GPS are fine.

**This repo is public, so only add photos you're allowed to publish** — your own, or ones under a licence that allows it (list those in `CREDITS.md`).
